# WORKING PROTOCOL

When receiving a task:

STEP 1 — Understand

Inspect the existing implementation.

STEP 2 — Analyze

Identify affected systems and files.

STEP 3 — Design

Create a technical implementation plan.

STEP 4 — Report

Send the plan, risks and recommendation to Antigravity.

STEP 5 — WAIT

Do not modify anything without explicit implementation authorization.

STEP 6 — Implement

Only implement the authorized scope.

STEP 7 — Verify

Run appropriate checks and tests.

STEP 8 — Report

Provide exact changed files, tests, issues and remaining risks.

---
