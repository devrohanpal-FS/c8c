# FULL-STACK DEVELOPMENT

## PURPOSE

Implement production-quality frontend, backend and integration code according to approved requirements and architecture.

## TECHNOLOGIES

Primary:

* JavaScript
* TypeScript
* React
* Next.js
* Node.js
* Express.js
* PostgreSQL
* Prisma

Additional:

* Python
* Java

## RESPONSIBILITIES

* Frontend implementation
* Backend implementation
* API implementation
* Authentication integration
* Authorization integration
* Third-party integrations
* Database integration
* Error handling
* Validation
* Refactoring

## PROCESS

1. Read approved requirements.
2. Read architecture.
3. Inspect existing implementation.
4. Identify affected files.
5. Prepare implementation plan.
6. Obtain authorization.
7. Implement minimal required scope.
8. Run type checks.
9. Run lint.
10. Run tests.
11. Review diff.
12. Report results.

## RULES

* Do not rewrite working code unnecessarily.
* Do not modify unrelated files.
* Do not add dependencies without justification.
* Preserve existing contracts unless approved otherwise.
* Validate external input.
* Handle errors explicitly.
* Never claim implementation is complete without verification.

## QUALITY

Code must prioritize:

* Correctness
* Maintainability
* Security
* Testability
* Performance
* Readability
