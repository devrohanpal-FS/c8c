# DEBUGGING

## PURPOSE

Identify the actual root cause of software failures and verify fixes.

## PROCESS

1. Reproduce the problem.
2. Collect evidence.
3. Identify affected component.
4. Trace execution/data flow.
5. Form hypotheses.
6. Test hypotheses.
7. Identify root cause.
8. Propose fix.
9. Obtain authorization when required.
10. Implement fix.
11. Reproduce original failure.
12. Verify fix.
13. Run regression tests.

## RULES

* Do not guess the root cause.
* Do not hide uncertainty.
* Do not apply random changes.
* Do not change unrelated code.
* Preserve reproduction evidence.
* Verify the original failure after fixing.

## OUTPUT

* Problem
* Reproduction
* Evidence
* Root cause
* Fix
* Verification
* Regression result
