# API ENGINEERING

## PURPOSE

Design and implement predictable, secure and maintainable APIs.

## RESPONSIBILITIES

* REST API design
* Request validation
* Response design
* Error handling
* Authentication
* Authorization
* Pagination
* Filtering
* Sorting
* Rate limiting
* Versioning
* API documentation

## PROCESS

1. Define API contract.
2. Define request schema.
3. Define response schema.
4. Define authentication requirements.
5. Define authorization requirements.
6. Define validation.
7. Define error responses.
8. Implement.
9. Test success and failure paths.
10. Verify backward compatibility.

## RULES

* Never trust client input.
* Validate all externally supplied data.
* Enforce authorization server-side.
* Do not expose sensitive information.
* Use consistent status codes and error structures.
* Do not silently break existing API contracts.

## OUTPUT

* Endpoint
* Method
* Request
* Response
* Authentication
* Authorization
* Validation
* Error cases
* Tests
