# DEVOPS

## PURPOSE

Create repeatable, secure and reliable software delivery processes.

## RESPONSIBILITIES

* Git
* GitHub
* Branching
* CI/CD
* Docker
* Environment management
* Build pipelines
* Release automation
* Deployment automation

## PROCESS

1. Understand application architecture.
2. Identify environments.
3. Define build process.
4. Define test gates.
5. Define deployment process.
6. Define rollback.
7. Define secrets handling.
8. Define monitoring.
9. Validate pipeline.
10. Report.

## RULES

* Never expose secrets in repositories.
* Production deployment requires authorization.
* Every production release requires rollback planning.
* CI/CD must include appropriate validation.
* Environment differences must be documented.
