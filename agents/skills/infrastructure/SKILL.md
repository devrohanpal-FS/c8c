# INFRASTRUCTURE

## PURPOSE

Design infrastructure appropriate for application requirements, traffic, reliability, security and budget.

## EVALUATE

* Cloud
* VPS
* Managed platforms
* Compute
* Database
* Storage
* CDN
* DNS
* SSL/TLS
* Networking
* Load balancing
* Autoscaling
* Caching
* Queues
* Monitoring
* Backups

## RESEARCH REQUIREMENT

When current provider information is required, perform fresh research.

Verify:

* Current pricing
* Resource limits
* Regions
* Concurrent connections
* Network limits
* Storage limits
* Database limits
* Autoscaling
* SLA
* Backup options

Never present outdated or assumed limits as facts.

## CAPACITY PLANNING

Estimate:

* Concurrent users
* Requests per second
* Database connections
* CPU
* RAM
* Storage
* Bandwidth

Clearly distinguish measured values from estimates.

## OUTPUT

* Architecture
* Capacity assumptions
* Provider comparison
* Costs
* Scaling strategy
* Reliability
* Security
* Trade-offs
* Recommendation
* Sources
